## Файловая структура
Файлы разбиты по папкам либо типу документов, которым они соответствуют (актёры, предметы, сцены и т.д.), либо по роли, 
которую они играют в модуле (раздаточные материалы, арты)
- `actors` — папка с изображениями для актёров
  - `portraits` — портреты актёров (полномасштабные изображения для демонстрации игрокам во время игры)
  - `subjects` — изображения для динамических рамок токенов
  - `tokens` — изображения для токенов, не использующих динамическую рамку
- `arts` — папка для различных изображений из текста приключения: иллюстраций, картинок обложек и т.д.
- `audio` — музыка и звуки
- `items` — изображения для предметов, например зелья исцеления или двуручного топора
- `scenes` — все изображения для сцен
  - `thumb` — изображения с миниатюрами сцен, которые используется самой FVTT для отображения списка сцен в меню
- `tiles` — изображения, которые используются для тайлов, размещаемых на сценах
- `ui` — вспомогательные изображения для улучшения интерфейса: иконки, фон журналов и прочее
- `handouts` — дополнительные раздаточные материалы
